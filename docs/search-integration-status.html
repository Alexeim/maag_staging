Поиск на Algolia: работает на сайте

Архив загружен в dev-индекс. Девять функций обрабатывают изменения материалов, отдельная функция проверяет журнал каждые 5 минут. С 24.11.2026 читатели ищут на странице /search; иконка поиска есть в шапке.

Кто за что отвечает

ЭлементОбязанность
FirestoreЕдинственный источник истины: оригинальные материалы. Существующая страница статьи читает их через backend.
AlgoliaПроизводная копия для поиска: текст, заголовок, ссылка и URL обложки. Изображение по URL загружает браузер.
ИмпортОдин раз обходит архив и записывает поисковые копии. После завершения не следит за правками.
ТриггерыПосле сохранения/удаления документа перечитывают его из Firestore и синхронизируют одну публикацию.
searchIndexSyncЖурнал без текста статей: версия, аренда, ошибка и срок проверки. Читатель им не пользуется.
searchVerifyПроверяет созревшие отметки журнала: до 50 публикаций за запуск, каждые 5 минут.

Что подтверждено

  • Первый импорт: 339 документов → 320 публикаций → 410 фрагментов, 8 закрытых публикаций; максимум 9 991 байт. Ошибок и предупреждений нет.
  • Полный обход индекса подтвердил прогноз импорта. Это исторический снимок, не постоянные текущие числа.
  • Все девять триггеров успешно созданы; проверка по расписанию развёрнута.
  • Подтверждён запуск проверки: 320 ожидали, 50 проверены, 0 исправлений, 0 ошибок, 270 отложены; ответ 200. Проверка всего остатка тогда отдельно не выполнялась.
  • Живая тестовая статья: черновик — 0 записей; публикация — 1 запись и совпавшие версии; удаление — 0 записей и версия deleted в журнале. Статья удалена.
  • Последний полный локальный серверный прогон: 200 тестов и обе проверки tsc прошли. При обновлении отчёта тесты заново не запускались.

Закрытые материалы

В индексе только title, tags, href, type, access, публичная imageUrl и технические поля; у интервью ещё interviewee. Нет content, introduction, лидов, цитат, подписей и первого абзаца. Ранее предложенный расширенный список «как на сайте» отменён.

Для first-person displayTitle содержит имя автора и хвост заголовка. Opinion сохраняет исходный title. Переименование автора/смена портрета пока требуют ручной пересинхронизации его материалов.

Гонки: что гарантируется и что нет

Аренда координирует одновременные обработки. Перечитывание выявляет новую версию. Отложенная сверка проверяет реальные objectID и sourceVersion в индексе независимо от syncedVersion журнала.

Таймаут не отменяет отправленный запрос: поздний старый batch может временно вернуть открытый текст после закрытия материала. Проверка исправляет это. Схема предполагает, что поздние записи доходят в пределах 10-минутного окна. После снятия отметки произвольно поздняя запись не гарантированно обнаруживается — полного регулярного обхода архива нет.

Правка текста, сокращение фрагментов, смена доступа, частичные и поздние batch проверены локально. Отдельный живой цикл этих переходов не проводился. Новые тестовые статьи пользователь создавать не хочет.

Поиск на сайте

  • Браузер обращается к Algolia напрямую с search-only ключом: только поиск, только maag_materials_dev, 1000 запросов/IP/час. Проверено: maag_pilot и выгрузка индекса — 403. Ключ записи в браузер не попадает; API его тоже не читает.
  • Результат — строка по образцу блока «ссылка на материал»: обложка (96px на телефоне), плашка, заголовок и отрывок с подсвеченным словом, «Читать далее». Клик открывает существующую страницу, которая читает Firestore через backend.
  • Подсветка безопасная: метки-маркеры вместо HTML, вывод только как текст.
  • Debounce 400 мс, Enter ищет сразу, пустой запрос не отправляется, старые ответы отбрасываются. «Ищем…», «Ничего не найдено», «Поиск не ответил». «Показать ещё» по 20.
  • Русские формы слов включены параметрами запроса: «святой антоний» находит «Святые угодники и колбасники» первой (без них было 0).
  • Страница закрыта от Google (noindex) и исключена из sitemap.
  • Задеплоено 24.11.2026: API maag-api-00116-28j, frontend maag-frontend-00303-qsj.

Не сделано

  • Клавиатура (↑↓ по результатам, Esc) — отложено до проверки командой.
  • Поиск по имени автора: «Должанский» не находит его материалы «От первого лица». Нужны изменения записей индекса и пересинхронизация.
  • Замер времени до появления результатов в браузере.
  • Production-индекс — отдельное решение.

Как продолжать

Очень маленькими согласованными шагами. Объяснять одно действие, зачем оно нужно и что оно меняет. Не вводить новые термины без объяснения. Commit только по команде, прямо в main; никаких .env-файлов в git. Облачные изменения, push и deploy согласуются отдельно.
